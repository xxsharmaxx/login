# 🔐 Login Page (Frontend)

## 📌 About
This project is a simple **Login Page UI** built using HTML and CSS.  
It demonstrates form design, input handling, and basic frontend layout for authentication pages.

---

## 🚀 Features
- 👤 Username / Email input field  
- 🔒 Password input field  
- ✅ Login button  
- 🎨 Clean and responsive UI  
- 🖥️ Simple and user-friendly design  

---

## 🛠 Tech Stack
- **HTML5** – structure  
- **CSS3** – styling  

---

## 📂 Project Structure
login-page/
│── index.html
│── style.css


---

## ▶️ How to Run
1. Download or clone the repository  
2. Open the project folder  
3. Run `index.html` in your browser
