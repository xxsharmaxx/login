# 🔐 Login Page (Frontend)

## 📌 About
This project is a simple **Login Page UI** built using HTML and CSS.  
It demonstrates form design, input handling, and basic frontend layout for authentication pages.

---

## 🚀 Features
- 👤 Username / Email input field  
- 🔒 Password input field  
- ✅ Login button  
- 🎨 Clean and responsive UI  
- 🖥️ Simple and user-friendly design  

---

## 🛠 Tech Stack
- **HTML5** – structure  
- **CSS3** – styling
